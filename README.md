# VPN Fundamentals

## Project Overview
This project explains Virtual Private Networks (VPNs) and how they protect network traffic over untrusted networks.

## Objectives
- Understand VPN architecture.
- Learn how VPN encryption protects data in transit.
- Understand secure remote connectivity.
- Distinguish VPN encryption from online anonymity.

## Tools Used
- Web Browser
- Google Docs
- GitHub

## How a VPN Works
A VPN creates an encrypted tunnel between a user's device and a VPN server. This tunnel helps protect traffic from being read by unauthorized parties on the local network.

## Security Benefits
- Protects traffic in transit between the device and VPN server.
- Improves security when using public Wi-Fi.
- Supports secure remote access to private networks.
- Can hide the user's public IP address from destination websites.

## Limitations
A VPN does not guarantee complete anonymity. Websites may still track users through cookies, account logins, and browser fingerprinting. Users must also trust their VPN provider.
